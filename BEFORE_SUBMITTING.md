# Do these before you submit (about 15 minutes)

1. Find and replace `YOUR-USERNAME` with your GitHub username in: README.md, robots.txt, sitemap.xml, and the canonical/og:url/og:image links in all 5 HTML files (use your editor's Find in Files).
2. Optional: create a free form at formspree.io and put its URL in `ENDPOINT` in js/main.js so enquiries become real emails. The enquiry form already works with a public test API.
3. Add the source of your instrument images and logo at the bottom of the README References.
4. Push with git_commits.sh (spread the commits over a few days) and turn on GitHub Pages (Settings > Pages > main / root).
5. Open every page on the live link and check it loads without errors, then add a "Deployed to GitHub Pages" line with the date to the changelog.
6. Submit the GitHub repository link on the LMS.
